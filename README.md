# La Baguetteria & Delicatezze — Carta Virtual

Carta virtual interactiva para **La Baguetteria & Delicatezze**.  
Sitio estático (HTML + CSS) listo para desplegar en **Vercel** o GitHub Pages.

## 📋 Secciones de la Carta

- ☀️ Desayunos
- 🥖 Sándwiches
- 🥟 Empanadas & Bocaditos
- 🥐 Croissants
- ☕ Café & Bebidas
- 🍰 Postres
- ✨ Adicionales

## 🚀 Despliegue en Vercel

1. Sube este repositorio a **GitHub**.
2. Ingresa a [vercel.com](https://vercel.com) y haz clic en **"Add New Project"**.
3. Selecciona tu repositorio de GitHub.
4. Vercel lo detecta automáticamente como sitio estático.
5. Haz clic en **Deploy** — ¡listo!
